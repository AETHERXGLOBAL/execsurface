# GitHub Discovery and Marketplace Readiness

ExecSurface is designed to be usable without prior contact with AETHER X.

## Recommended repository topics

Repository maintainers should keep these GitHub topics attached to the public repository:

- `developer-tools`
- `runtime-security`
- `supply-chain-security`
- `devsecops`
- `github-actions`
- `ci-cd`
- `rust`
- `runtime-observability`
- `software-supply-chain`
- `security-tools`

These topics are descriptive discovery metadata only. They do not broaden the product's security claims.

## GitHub Marketplace

The public Action is intended for the stable `AETHERXGLOBAL/execsurface@v0.1` channel.

Marketplace copy should preserve these boundaries:

**Name:** ExecSurface — Runtime Drift Detection

**Short description:** Detect runtime execution-surface drift in CI and developer workflows using an explicit baseline and policy.

**Category:** Security / Utilities

**Public support boundary:** Linux x86_64; native ptrace correctness-reference backend.

Do not describe ExecSurface as antivirus, EDR, malware detection, sandboxing, or proof of software safety.

## Independent evaluation

Evaluators can run the complete self-service path in [`INDEPENDENT_EVALUATION.md`](INDEPENDENT_EVALUATION.md) and submit results through the repository's **Independent Evaluation** issue form.

No prior approval, meeting, email, or private onboarding is required.

Negative and partial evidence are accepted and must remain preserved as reported.
