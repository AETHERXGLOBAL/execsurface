## What advances in Alpha.5

- Stronger semantics-preserving handling of the current evidence model, keeping ambiguous or incomplete evidence non-PASS-eligible.
- Stronger proposition/backend authority boundaries.
- Stronger legitimate-variance handling while retaining anti-poisoning constraints.
- Stronger attestation, provenance, executable binding and release-artifact verification.
- Improved usability, packaging and reproducibility qualification.
- Portable release construction on Ubuntu 22.04 with public-artifact verification on Ubuntu 22.04 and Ubuntu 24.04.

## Public support boundary

- Linux x86_64 is the public support scope for this alpha.
- Native ptrace remains the bounded public reference observer.
- ARM64 support is not claimed.
- Observed behavior is not all possible behavior.
- ExecSurface is not antivirus, EDR, SIEM, sandbox, malware detection or proof of software safety.
- Incomplete or ambiguous evidence cannot silently become PASS.
