## CLI self-service

Added:

- `execsurface --version`
- `execsurface doctor`
- `execsurface init --command "..." --github-actions`

### doctor

The supported-environment proof checks:

- Linux
- x86_64
- a real child ptrace observation
- workspace writeability
- product version

It does not:

- elevate privileges
- change `kernel.yama.ptrace_scope`
- add capabilities
- change system security settings

### init

The initializer:

- writes a starter policy;
- optionally writes a GitHub Actions workflow;
- prints wrapper-consistent explicit learn/check commands;
- does not execute the supplied target command;
- refuses overwrite without explicit `--force`.
