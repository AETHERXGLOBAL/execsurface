## Result

M3 adds a deterministic, content-addressed baseline layer on top of the M2 canonical execution surface.

Implemented:

- `execsurface-baseline` Rust crate;
- lock schema version `1`;
- digest-format version `1`;
- `schemas/execsurface-lock-v1.schema.json`;
- `execsurface learn -- COMMAND`;
- default `execsurface.lock.json` output;
- explicit `--output` override;
- explicit `--overwrite` requirement;
- same-directory temporary-file publication;
- target-success requirement;
- parse + digest verification API.

M3 does not implement candidate diff or policy.

## Digest contract v1

Algorithm:

`SHA-256`

Digest input:

> minified UTF-8 JSON of `{"schema_version":1,"payload":<BaselinePayload>}`

The `baseline_digest` field is excluded from its own digest.

Digest output:

`sha256:<64 lowercase hex characters>`

No unordered map is present in the digest payload.

Before hashing, generated payload order is normalized for:

- observer capabilities;
- observer limitations;
- semantic-root labels;
- canonical effects.

No timestamp enters the lock payload.

Status: **PROVED BY EXECUTABLE FORMAT CONTRACT + COMPUTATIONAL_EVIDENCE**

## Behavioral sensitivity

Adding a controlled canonical network effect to the fixture changes the baseline digest.

Status: **COMPUTATIONAL_EVIDENCE**

This proves the tested content-addressing property; it is not a collision-resistance proof beyond the SHA-256 assumption.

## Publication semantics

Without `--overwrite`:

- publication uses a same-directory temporary file;
- hard-link publication fails if the target already exists;
- an existing baseline is not silently replaced.

With explicit `--overwrite`:

- the temporary file is renamed over the requested path.

The file and parent directory are synced in the implementation.

Status: **PROVED BY IMPLEMENTATION + TESTED FOR CONTROLLED FILESYSTEM FIXTURE**

## Target failure behavior

A non-zero/signaled target is not learned as a baseline by default.

The integration test runs `/bin/false` and verifies:

- `learn` returns failure;
- no baseline file is created.

Status: **COMPUTATIONAL_EVIDENCE**
