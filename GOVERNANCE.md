# Governance

AETHER X GLOBAL maintains ExecSurface as an open-source engineering project.

Architecture-changing decisions use committed ADRs and milestone gates.

Core principles:
- evidence before claims,
- baseline separate from policy,
- privacy-safe defaults,
- explicit observer limitations,
- deterministic outputs where promised,
- preserve negative results.

## IP review

If a component may contain strategically sensitive IP, stop public publication of that component and mark it:

**IP REVIEW REQUIRED**

No claim of patentability, novelty or first-in-world status is made without dedicated prior-art review.
