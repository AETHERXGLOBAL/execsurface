# Code of Conduct

ExecSurface is an evidence-oriented open-source engineering project.

## Expected behavior

Contributors and maintainers are expected to:

- discuss technical claims using reproducible evidence;
- critique ideas and implementations rather than people;
- disclose uncertainty and limitations;
- preserve negative results that materially affect a claim;
- avoid publishing another person's private or confidential information;
- keep security reports out of public threads when disclosure would create risk.

## Unacceptable behavior

The project does not accept:

- harassment or threats;
- discriminatory or degrading comments;
- doxxing or publication of private information;
- deliberate disruption of technical collaboration;
- knowingly fabricated benchmark, security or adoption claims;
- pressure to hide a material failed test or evidence gap.

## Enforcement

Repository maintainers may edit, hide or remove content; close or lock threads; reject contributions; or restrict participation when behavior materially violates these standards.

Enforcement should be proportionate and documented when public documentation does not itself create a privacy or safety problem.

## Reporting

For ordinary repository conduct problems, contact the maintainers through the relevant GitHub thread with the minimum necessary information.

If a report includes sensitive personal information or a security issue, do not post it publicly. Use GitHub's private vulnerability reporting when available and state that the report requires confidential maintainer review.

This project does not require a contributor to disclose private identity information in order to participate.
