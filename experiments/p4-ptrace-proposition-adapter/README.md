# P4 Ptrace Proposition Adapter — Research Only

This experiment implements the P4-A1 research-only proposition record boundary.

It is not a public API, observer backend, release component, or claim of backend equivalence.

Current stage: A1.1 only — proposition record types, validation and deterministic serialization. Collector binding is intentionally absent until A1.1 passes its frozen tests.

Public `v0.1.0-alpha.4`, raw-v2 observation semantics and default ptrace behavior remain unchanged.
